# 安全审查规范

## 后端安全

- [ ] SQL 注入：使用参数化查询或 ORM
- [ ] 命令注入：不拼接用户输入到 shell 命令
- [ ] 路径遍历：验证用户提供的文件路径
- [ ] 敏感信息：不在日志或错误信息中暴露密钥
- [ ] 上传文件：限制文件类型、大小，验证内容
- [ ] 配置下发：接口需要鉴权，防止未授权修改 Prometheus 配置

## 前端安全

- [ ] XSS：不直接插入用户输入到 DOM
- [ ] CSRF：使用 SameSite Cookie 或 CSRF Token
- [ ] 敏感信息：不在前端硬编码密钥

## 部署安全

- [ ] 不提交 `.env`、密钥文件到 Git
- [ ] 容器以非 root 用户运行
- [ ] 最小化镜像权限

## 特别关注点

MetricCenter 涉及向 Prometheus 写入配置文件，必须确保：
1. 只有授权用户可以下发配置
2. 下发的配置经过校验，避免破坏 Prometheus 运行
3. 配置变更记录审计日志
