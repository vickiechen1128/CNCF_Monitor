## 4. 验收项明细（核心）

> 每行一个可验收项，由 Scenario Link「验收（需求方语言）」+ acceptance「FR/NFR 证据」翻译而来。**业务语言，不出现 FR/CAP/mXX 编号。**
> - **粒度**：以「客户一次演示 / 验证能确认」为粒度，1 条对外验收项 ≈ 1~3 条对内 FR/NFR，不逐条照搬 FR 编号。
> - 验收方法枚举：`演示` / `测试`（附测试报告）/ `文档审查`
> - 结论枚举：`通过` / `有条件通过` / `不通过` / `待验证`
> - **结论映射（对内 → 对外）**：`done → 通过`、`partial → 有条件通过`、`open / 未测 → 待验证`、`失败 → 不通过`
> - T0 只填「验收项 + 验收标准」，T1 补「验收方法」，T2 锁定方法，T3 回填「证据 + 结论」
