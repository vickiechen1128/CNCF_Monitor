## 2. 系统概述（业务语言）

配置与查询中心解决一个核心问题：**采集节点如何接入中心，接入后用户如何查看目标状态、查询指标并追溯配置**。

它把「让网域接入监控 → 让采集节点拉配置出数据 → 让用户查目标与指标」串成一条闭环：

- 每个网络区域（网域）接入监控时，由平台自动签发接入凭据、提供安装指引与离线包；
- 部署在网域内的采集节点负责抓取/拨测/回传指标，并定期向中心上报心跳与目标状态；
- 用户在统一界面查看节点是否在线、目标是否采到数据、查询指标趋势、回溯当时的配置。

安全上，中心不主动连接采集节点，所有指令由节点主动拉取执行；不同网域的数据相互隔离。

## 3. 功能域与功能清单

> 由业务场景翻译而来，按客户可感知的「功能域」组织。以下五个功能域对应系统内五个菜单。

| 功能域 | 功能 | 说明（业务语言） |
|--------|------|------------------|
| 网域纳管 | 网域接入监控 | 选择已登记网域完成纳管，自动签发接入凭据 |
| | 凭据管理 | 凭据脱敏展示、单次复制、重置后旧凭据失效 |
| | 安装指引与离线包 | 统一安装指引 + 离线包下载（含完整性校验） |
| 采集节点状态 | 节点注册与在线判定 | 首次心跳自动注册，按心跳判定在线/离线 |
| | 节点运行态观测 | 展示配置同步状态、组件运行态、crash-loop |
| | 远程操作 | 远程重启采集进程、清空回传积压 |
| 监控目标状态 | 目标健康状态 | 展示每个采集目标的健康状态、最近错误 |
| | 采集覆盖率 | 展示采集中/部分/未采到/未监控四态 |
| 指标查询 | 指标查询 | Prometheus 兼容的即时/区间/标签/告警查询 |
| | 查询隔离与元信息 | 按网域自动隔离，结果附来源/新鲜度 |
| | 指标查询页面 | 时序图、结果明细、URL 复现 |
| 配置产物历史 | 自动配置生成 | 源数据变化后自动生成配置，失败不覆盖当前 |
| | 统一产物历史 | 三类配置统一只读展示、内容预览、导出 |
| | 告警配置引用 | 告警配置以只读方式纳入统一历史 |
| | 离线包版本 | 离线包版本列表与差异提示 |
