原型访问方式

每个模块都是独立的 Vite + React 原型项目。下面提供两种访问模式：开发模式（各模块独立热更新）和构建模式（统一静态部署后一次性浏览）。

开发模式下，每个模块需要单独启动一个 dev server。点击下方「打开模块」会访问默认端口，若端口冲突请手动修改对应模块的 vite.config.ts。
构建模式下，先执行 ./build-all.sh 构建全部模块，再用静态服务器托管 docs/prototypes/ 目录，即可通过统一入口访问所有已构建模块。
# 构建全部模块 cd docs/prototypes ./build-all.sh # 方式 1：使用 Python 静态服务器 python3 -m http.server 8080 # 方式 2：使用 Node 静态服务器（需安装 serve） npx serve -l 8080 # 访问统一入口 open http://localhost:8080/
