# Module 06 开发问题反馈单（dev-feedback）

> 用途：记录开发（`feat` 分支）发现的 PRD / 原型**细节问题**，作为对设计侧的**变更请求单**。PRD / 原型文件与版本号**禁止改动**（红线，见 `03_Code_Collaboration_Workflow.md` §6 / §6.1）。
>
> 填写方：backend-developer / frontend-developer（05 目录为 agent 可写区）
> 收割方：chenrt（PM，在 `design/module-mvp-demo` 分支做一轮版本化迭代时一次性收割，收割后在本单标「已收割于 vX.X」）

## 三类问题处置速查

| 类型                   | 例子                | 处置权                                              |
| -------------------- | ----------------- | ------------------------------------------------ |
| ① PRD **空白**（未规定）    | 边界值、校验细节、字段长度上限   | 开发可直接定，**必须在此留痕**                                |
| ② PRD **已规定但实现发现矛盾** | 字段语义与真实数据对不上      | **不计入本单**——必须**实现前**报告 PM / Orchestrator 走 CR 决策 |
| ③ 原型**纯技术优化**        | 组件结构、mock 修复、交互细节 | 同 ①，在此留痕即可                                       |

> ⚠️ ② 类（矛盾）禁止事后塞进本单当既成事实；本单只承载 ①空白 / ③技术优化。
