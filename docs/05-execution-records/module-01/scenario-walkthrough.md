## SCN-01 新增一种采集能力（NPU）

- **前置**：M07 已登记带 `has_npu=true` 的主机；采集实现 `npu-exporter` 已登记；`host` 类别标签模板可用；已有 Linux 主机采集任务。
- **步骤**：
  1. 进入「采集策略 → 采集模板」，新增 `host_npu`：资源类别 `host`、采集实现 npu-exporter、填写端口/间隔、绑定标签模板；
  2. 保存后回到模板列表，确认新模板可见；
  3. 进入「采集任务 → 新建」，确认下拉中立即出现 `host_npu`；
  4. 选择该模板，添加条件 `has_npu 等于 true`，查看命中数与分域预览；
  5. 确认实例并保存；
  6. 在任务列表与详情查看同步状态、实例采集状态；
  7. 回到原 Linux 主机任务，确认其配置与同步状态未受影响。
- **预期结果**：
  - 模板保存后无需刷新/重启即可用于新建任务；
  - 命中数与 M07 中 `has_npu=true` 的主机数一致；
  - 同一主机同时出现在 OS 任务与 NPU 任务的已选实例中；
  - 两条任务同步状态彼此独立；
  - 实例详情显示端口来源为「模板默认」或「采集实现默认」（未设置 `scrape_port` 时），与端口链口径一致。

## SCN-02 创建跨网域采集任务（对象优先）

- **前置**：两个及以上网域已在 M06 登记并在 M09 纳管；MySQL 资源分布在不同网域；MySQL 采集模板与标签模板可用。
- **步骤**：
  1. 进入「采集任务」，点击「新建采集任务」；
  2. 选择任务类型（采集）与 MySQL 采集模板；
  3. 添加筛选条件（如 `database_type 等于 mysql`），查看总命中数与各网域命中数；
  4. 确认或排除个别实例，保存；
  5. 在列表查看覆盖网域聚合与逐域子任务；
  6. 执行整组停用，再重新启用；
  7. 查看组级同步状态与各子任务同步状态。
- **预期结果**：
  - 网域不是表单第一个必填项；
  - 保存前可见分域命中；
  - 保存后按实例所属网域生成多条单域子任务；
  - 停用后子任务不再进入同步候选，重新启用回到待同步；
  - 启用前校验每个子任务至少保留一个实例。

## SCN-03 配置并检查告警规则

- **前置**：存在可同步的采集任务；`promtool` 在 PATH。
- **步骤**：
  1. 进入「规则编辑」，粘贴 `rules.yml`；
  2. 点击「检查」，查看组数、规则数、PromQL 校验状态；
  3. 构造一个引用不存在 Job 的存活类规则，确认被 error 阻断；
  4. 构造一个引用不存在 Job 的非存活类规则，确认 warning 且可提交；
  5. 修正后重新检查并提交；
  6. 查看规则同步状态，确认中心 Prometheus 已加载。
- **预期结果**：
  - 检查结果可定位到具体组/规则；
  - error 阻断提交，warning 高亮但允许提交；
  - 组名重复被检查拦截；
  - 内容修改后原检查结论作废；
  - 提交后进入待同步，最终同步成功并由中心集中求值。
- **实测结果**：待填

## SCN-04 排查同步失败与采集异常

- **前置**：存在已保存任务；至少一个实例可被置为离线；可访问 M09 配置产物与目标状态。
- **步骤**：
  1. 在任务列表查看同步状态；构造一次校验失败（如非法采集间隔），观察失败状态与原因；
  2. 跳转配置产物/校验详情，确认归因为用户配置还是平台故障；
  3. 修正后重新保存，观察状态从待同步到已同步；
  4. 在任务详情查看实例级采集状态（待采集 / 在线 / 回传延迟 / 离线 / 未知）与生效端口来源（实例 / 模板 / 采集实现默认 / 业务端口 / 未解析）；
  5. 在 M07 删除一个已选资源，等待对账周期（默认 60s）；
  6. 回到任务详情确认该实例已回收，M09 下一周期 target 已移除。
- **预期结果**：
  - 同步失败不锁死源数据，可编辑后重新触发；
  - 失败原因可读，能区分用户配置与平台故障；
  - 实例状态与 M09 目标状态口径一致；
  - 资源删除后任务内不再残留该实例。
- **实测结果**：待填

## SCN-05 采集模板治理与变更影响

- **前置**：存在被采集任务与指标锚点引用的自定义采集模板；至少一个内置模板。
- **步骤**：
  1. 在采集模板列表查看引用数与影响面；
  2. 停用该模板，尝试新建任务确认不可选；
  3. 编辑模板参数（默认端口 + 采集间隔），查看存量任务参数是否保持不变；
  4. 在存量任务中执行「同步模板默认值」；
  5. 尝试删除仍有引用的模板，查看拒绝提示与引用清单；
  6. 尝试删除内置模板，确认仅可停用。
- **预期结果**：
  - 停用后不可新建，存量任务保留并提示「采集模板已停用」；
  - 采集间隔等参数变更不影响存量任务快照；模板默认端口按端口链在下次预览 / 生成时生效，Job 快照中无端口字段；
  - 「同步模板默认值」只重算参数快照，不改变端口链求值；
  - 删除保护生效并回传引用清单；
  - 内置模板不可删除。
- **实测结果**：待填

## SCN-06 维护技术指标库

- **前置**：存在采集模板；准备管理员与普通登录用户各一个。
- **步骤**：
  1. 以普通用户进入「指标库」，确认无新增/编辑/删除入口；
  2. 以普通用户直调写接口，确认返回 403；
  3. 以管理员查看内置指标，确认不可编辑；
  4. 新增用户扩展指标并挂接目标采集模板；
  5. 重复登记同名同锚点指标，确认被拒绝；
  6. 在指标库筛选中选择刚新增的模板，确认无需刷新即可选到。
- **预期结果**：
  - 非管理员无写入口且服务端 403；
  - 内置指标只读；
  - 用户扩展指标可新增/编辑/删除；
  - 同名同锚点重复登记被拒；
  - 模板筛选项随模板变化即时可用。
- **实测结果**：待填
