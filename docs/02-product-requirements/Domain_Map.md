# 业务域 ↔ 实现模块映射

> **用途**：把需求方的**业务域（DOMAIN）**与技术侧的**实现模块（mXX）**分开。
> **规则**：SRS 用 DOMAIN + SCN；HLD / 代码 / 分支 / 任务用 mXX；Scenario Link 负责映射。
> **注意**：实现模块是代码归属，不等于需求边界；一个业务域可以跨多个实现模块。

| Domain ID | 业务域 | 实现模块（技术侧） | 说明 |
|-----------|--------|--------------------|------|
| `DOMAIN-CFG-QUERY` | 配置与查询中心 | `m09`（主）+ `m06` / `m07`（依赖/引用） | 网域纳管、采集节点、配置发布、目标状态、指标查询 |
| `DOMAIN-M01` | 采集策略与指标 | `m01` | 采集模板、采集任务、规则、指标库 |
| `DOMAIN-M05` | 可视化中心 | `m05` | 首页/看板 |
| `DOMAIN-M06` | 系统与平台管理 | `m06` | 租户、用户、网域行政、平台配置 |
| `DOMAIN-M07` | 监控对象管理 | `m07` | 资源、标签模板、导入导出 |
| `DOMAIN-M08` | 告警收敛与通知 | `m08` | Alertmanager 配置、路由、静默、抑制、通知 |

> 历史 `Module_XX` 文件名/编号仅作工程索引；新增 SRS 建议按业务域命名，例如 `Configuration_And_Query_Center_SRS.md`。
